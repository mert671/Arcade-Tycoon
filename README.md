# 🕹️ Arcade Tycoon

**Arcade Tycoon**, kendi atari salonunuzu kurup işlettiğiniz, eğlenceli ve bağımlılık yapıcı bir mobil oyun projesidir! 

---

## 📱 İndir & Oyna

Oyunu hemen Android telefonunuza kurmak ve denemek için en son sürümü indirebilirsiniz:

👉 **[En Son Sürüm APK'sını İndir](https://github.com/mert671/Arcade-Tycoon/releases)**

---

## 🚀 Özellikler

* **Atari Salonu Yönetimi:** Kendi makinelerinizi yerleştirin, salonunuzu büyütün.
* **Mobil Uyumlu:** Android cihazlar için özel olarak optimize edilmiştir.
* **Eğlenceli Oynanış:** Klasik atari kültürü ve tycoon dinamikleri bir arada.

---

## 🛠️ Teknolojiler

Bu proje şu teknolojiler/araçlar kullanılarak geliştirilmiştir:
* HTML / CSS / JavaScript (veya projenizin kullandığı diller)
* Acode / Termux mobil geliştirme ortamı
